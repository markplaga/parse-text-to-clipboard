# Parse Text to Clipboard

A lightweight browser tool for stepping through multiline text one entry at a time and copying each entry to the clipboard.

## Features

- Paste text directly from the clipboard
- Split text into non-empty lines or paragraphs
- Copy the next entry with one click
- Track progress through the list
- Reset the session when finished

## Technology

- HTML
- CSS
- Vanilla JavaScript

## Use

Open `index.html` in a browser, paste or enter text, and press **Copy next entry** to move through the content sequentially.
